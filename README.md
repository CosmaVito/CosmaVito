# Cosma Vito Iaffaldano

Full-stack developer with more than 10 years in enterprise web applications. I design architectures, lead small teams and still write code every day in .NET and Angular.

I build security into the delivery pipeline: static analysis, dependency and secret scanning and an SBOM run on every build, and a release that fails them does not ship.

- Angular with signals, Blazor WebAssembly, React, TypeScript
- PostgreSQL, SQL Server, MongoDB, Redis, Elasticsearch, RabbitMQ
- Keycloak and OpenID Connect, Docker, Azure

**Security and compliance**
- CI/CD security gates with SAST, SCA, Trivy and Gitleaks, plus SBOM and CVE tracking

**Performance**

**Websites for small businesses**

- Accessibility checks with axe on every build
