# Cosma Vito Iaffaldano

Technical Lead & Delivery Manager, with more than 10 years in enterprise web applications. I take projects from the first analysis with the client to the production release: I design the architecture, lead the team and still write code every day in .NET and Angular.

I build security into the delivery pipeline: static analysis, dependency and secret scanning and an SBOM run on every build, and a release that fails them does not ship.

## What I work on

**Business applications**
- .NET 8 to 10, ASP.NET Core Minimal APIs, .NET Aspire, Clean Architecture and CQRS
- Angular with signals, Blazor WebAssembly, React, TypeScript
- PostgreSQL, SQL Server, MongoDB, Redis, Elasticsearch, RabbitMQ
- Keycloak and OpenID Connect, Docker, Azure

**Security and compliance**
- CI/CD security gates with SAST, SCA, Trivy and Gitleaks, plus SBOM and CVE tracking
- Release documentation aligned with the EU Cyber Resilience Act
- GDPR by design: data minimisation and pseudonymisation
- [cra-trail](https://github.com/CosmaVito/cra-trail), my open-source CLI that builds Cyber Resilience Act evidence packs (SBOM, scans, VEX, Annex I evaluation) and gates the release

**Performance**
- JavaScript and TypeScript memory leaks, Entity Framework query tuning, ThreadPool starvation

**Tooling**
- Claude and GitHub Copilot every day for development, analysis, debugging and documentation
- Agentic workflows with planning, extended thinking and reusable skills

**Websites for small businesses**
- Static sites built with Astro and deployed on Cloudflare
- Cookie consent designed around the guidelines of the Italian Data Protection Authority (Garante)
- Accessibility checks with axe on every build
